# Aldemir Software — Uzay görsel dili

Derin gece mavisi, metalik gümüş, buz mavisi ışıklar, Dünya ufku ve şeffaf cam yüzeyler.

## Üretilen web sahneleri

Yerleşime özel iki yazısız görsel, referanslardaki atmosferle yerleşik Imagegen aracı kullanılarak üretildi. Logo ve başlıklar HTML katmanlarıdır. Kaynak görseller değiştirilmedi; site kopyaları yalnızca JPEG olarak kodlandı.

## Görsellerden siteye aktarılan mesajlar

- Açılış: Markanızı geleceğin yörüngesine taşıyoruz.
- Çözümler: Fikrinizi yörüngeye taşıyan altyapı.
- Web: Markanıza güç katan web çözümleri.
- Yazılım: İşinizi yöneten akıllı sistemler.
- Mobil: Markanızı cebe taşıyan uygulamalar.
- Bulut: Bugünden yarına hazır olun.
- Veri: Kararlarınızı güçlendiren veri ve raporlama sistemleri.
- Strateji: Görünürlüğün arkasındaki strateji.
- Yaklaşım: Dijital gücün 3 temeli — Denge, Strateji, Sadelik.
- Mühendislik: Görünenden daha fazlasını inşa ediyoruz.
- Kurumsal: Teknolojide sınır yok. Hedeflerinizde de olmasın.
- İletişim: Projelerinizi birlikte yörüngeye taşıyalım.

## Gönderilen görsellerin kullanımı

Hizmet ve yaklaşım kartları kullanıcının sağladığı orijinal görsellerin JPEG kopyalarını kullanır. Kartların görsel pencereleri CSS ile düzenlenir; orijinaller assets/ altında korunur. Ana sloganlar görüntü içine gömülmez, erişilebilir HTML metinleri olarak sunulur. Referanslardaki dekoratif performans yüzdeleri hizmet garantisi olarak aktarılmamıştır.
